To allow the website to access data from the database, first switch to the backend directory and start the server using "node server.cjs" in the terminal, then start the website from the world-public-transport directory in a second terminal as usual

I used this tutorial https://www.youtube.com/watch?v=LQL-0MCH8XE&list=PLB4OYaYkKsG67m29ynu_k3NykUUNuTn0P to setup the database and everything needed to interact with it so most of backend code comes from there
